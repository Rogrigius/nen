# nen — Discord-бот персональных звуков входа и выхода

Бот отслеживает входы и выходы пользователей в голосовых каналах. Когда пользователь, для которого настроен звук, заходит в голосовой канал, бот подключается к тому же каналу, ждёт настраиваемое время (по умолчанию 4 секунды) и проигрывает персональный звук этого пользователя, после чего отключается от канала. Когда пользователь выходит из голосового канала, бот сразу заходит в только что покинутый канал, проигрывает звук выхода (если он настроен) и отключается.

## Возможности

- Реакция на вход в голосовой канал и на переход между каналами (переход считается новым входом).
- Звук выхода при полном выходе из голосовых каналов — проигрывается сразу, без задержки. При переходе между каналами звук выхода не играет.
- Персональные звуки входа и выхода для каждого пользователя (привязка в `config/users.json`).
- Анти-спам: не чаще одного срабатывания в минуту на пользователя отдельно для входа и для выхода.
- Если бот уже играет в голосовом канале этого сервера, повторно он не заходит.
- Ботов и события, не связанные со входом или выходом (мьют, дефен в том же канале), бот игнорирует.

## Требования

- Node.js 18 или новее.
- Устанавливать ffmpeg отдельно **не нужно**: он ставится автоматически вместе с зависимостями через пакет `ffmpeg-static`.

## Установка

```bash
npm install
```

## Создание бота на Discord Developer Portal

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) и нажмите **New Application**, задайте имя.
2. Перейдите в раздел **Bot** слева и нажмите **Reset Token** — скопируйте токен. Он понадобится для `.env`.
3. Никаких привилегированных интентов (Privileged Gateway Intents) включать не требуется: бот использует интенты **Guilds** и **GuildVoiceStates**, они не являются привилегированными и задаются в коде.

## Приглашение бота на сервер

1. На Developer Portal откройте раздел **OAuth2 → URL Generator**.
2. В scopes отметьте **bot**.
3. В Bot Permissions отметьте **View Channel**, **Connect** и **Speak** (соответствует числовому значению `3146752`).
4. Откройте сгенерированную ссылку в браузере и выберите свой сервер.

Ссылка также имеет вид (подставьте Client ID вашего приложения):

```
https://discord.com/oauth2/authorize?client_id=ВАШ_CLIENT_ID&scope=bot&permissions=3146752
```

## Настройка

### 1. Токен

Скопируйте `.env.example` в `.env` и вставьте токен бота:

```bash
cp .env.example .env
```

```
DISCORD_TOKEN=ваш_токен
```

Файл `.env` добавлен в `.gitignore` и не попадёт в репозиторий.

### 2. ID пользователя

1. В Discord откройте **Настройки пользователя → Дополнительно** и включите **Режим разработчика**.
2. Нажмите правой кнопкой по нужному пользователю и выберите **Копировать ID пользователя**.

### 3. Привязка звуков

Отредактируйте `config/users.json` — это объект, где ключ — ID пользователя, а значение — либо имя файла из папки `sounds/` (звук входа), либо объект с полями `join` (звук входа) и `leave` (звук выхода); оба поля необязательны, но нужно указать хотя бы одно:

```json
{
  "123456789012345678": {
    "join": "sound1.mp3",
    "leave": "leave1.mp3"
  },
  "234567890123456789": "sound2.mp3"
}
```

Запись-строка `"id": "файл.mp3"` эквивалентна `"id": { "join": "файл.mp3" }` — звука выхода у такого пользователя нет.

Звук выхода проигрывается сразу после того, как пользователь покинул голосовой канал (без задержки `JOIN_DELAY_MS`), и только при полном выходе из голосовых каналов; переход в другой канал считается входом.

Звуковые файлы кладите в папку `sounds/` (поддерживаются форматы, которые понимает ffmpeg: mp3, ogg, wav и др.). В репозитории уже лежат короткие примеры — `sound1.mp3`, `sound2.mp3` и `leave1.mp3`, сгенерированные через ffmpeg.

### 4. Задержка перед проигрыванием (необязательно)

Пауза между подключением бота к каналу и началом проигрывания настраивается переменной окружения `JOIN_DELAY_MS` (в миллисекундах) в файле `.env`:

```
JOIN_DELAY_MS=1500
```

По умолчанию — `4000` (4 секунды). Значение должно быть положительным числом; при некорректном значении бот выведет предупреждение в лог и использует значение по умолчанию. На звук выхода эта задержка не влияет.

## Запуск

```bash
npm start
```

При старте бот проверяет наличие токена и конфига. Без `DISCORD_TOKEN` он завершится с понятной ошибкой.

## Структура проекта

```
├── src/index.js      — код бота (событие voiceStateUpdate, подключение и проигрывание)
├── config/users.json — привязка «userId → звук входа / звук выхода»
├── sounds/           — звуковые файлы (три примера в комплекте)
├── .env.example      — образец файла с переменными окружения (токен, задержка)
└── package.json      — зависимости и скрипт запуска
```
